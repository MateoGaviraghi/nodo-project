## 4. Conventions (how code is actually written here)

**File naming & structure:**
- Components: PascalCase, `src/components/[section]/ComponentName.tsx`
- Pages: lowercase slug, `src/app/[slug]/page.tsx` (App Router convention)
- Hooks: camelCase, `src/hooks/useX.ts`, export as named function
- API routes: lowercase slug, `src/app/api/[resource]/route.ts`
- Types: centralized in `src/types/index.ts` or colocated if single-use
- `"use client"` directive at top of client components; server components default

**Code style:**
- Imports: grouped (React/Next → third-party → local), using `@/*` alias for src/
- Component structure: const Component = () => { ... }; export default Component;
- Props: interface typed, destructured in params
- State: useState, useCallback, useContext (context is the pattern for global state like language)
- Animations: Framer Motion for interactive (springs, gestures), GSAP ScrollTrigger for scroll effects
- Styling: Tailwind first (clsx for conditional), CSS module (rare), CSS-in-JS (none — avoid)
- Error handling: try/catch in API routes, optional chaining in components
- Translations: always via `useLanguage()` hook → `const { t } = useLanguage(); t.section.key`

**Animation patterns (CRITICAL):**
- **Hero (scroll-driven):** GSAP ScrollTrigger + scrub on 122 JPG frames. Height: 350vh (mobile) / 600vh (desktop). ReferenceError if frames not loaded.
- **Post-hero sections:** IntersectionObserver (native) + CSS transition classes — DO NOT mix GSAP fromTo/timeline here (conflicts with Lenis).
- **3D (R3F Canvas):** Dynamic import, SSR disabled. NEVER opacity:0 or clip-path on Canvas parent — WebGL init fails.
- **Microinteractions:** Framer Motion (spring damping ~5-8), gesture handlers (onHoverStart/End), blur + scale on entrance.
- **Marquee/Infinite scroll:** CSS @keyframes marquee (35s linear infinite).

**Lenis + GSAP rules (non-negotiable):**
- Lenis duration: 0.8s
- NO `scroll-behavior: smooth` in CSS when Lenis active
- Post-hero sections: IntersectionObserver only, no GSAP opacity/y animations
- Hero ScrollTrigger scrub: OK, it's integrated
- ScrollToTop: use `lenis.scrollTo(0)`, not `window.scrollTo()`

**Language/i18n:**
- All copy lives in `src/lib/translations.ts`, exported as `translations: { es: {...}, en: {...} }`
- Bilingual component usage: `const { t } = useLanguage(); t.section.key`
- Default language: ES. localStorage key: "nodo-language"

**Database/API patterns:**

- Email: Resend API (branded emails, templates)

## 7. Decisions & why

**Next.js 16 App Router (not Pages Router):**
- Server components by default (better perf, no JS for static content)
- File-based routing (cleaner than _document + _app)
- App-level layout (Navbar, Footer centralized)
- Streaming + dynamic import for code splitting

**Tailwind v4 (@theme tokens):**
- Design tokens centralized in CSS, no magic strings
- Minimal build output (purges unused)
- Works with TypeScript for type-safe styling

**GSAP + Lenis combo (not scroll-behavior: smooth + CSS scrolling):**
- ScrollTrigger frame scrubbing (hero, 122 JPG frames)
- Smooth scroll without conflicts (Lenis handles physics)
- But: post-hero sections use IntersectionObserver (GSAP conflicts with Lenis in those regions)

**Context API for language (not Redux/Zustand):**
- Simpler for 2-language toggle
- localStorage for persistence
- Avoids bundle size

**Supabase (not Firebase):**
- PostgreSQL (relational, familiar)
- OAuth integration built-in
- Row-level security (future-proof)
- S3-compatible storage

**Dynamic import SSR=false for R3F (Canvas):**
- WebGL init fails if Canvas parent is hidden initially
- Deferring render to client, skipping SSR, prevents hydration mismatch

**Codec Pro custom font (not system fonts):**
- Brand identity (geometric, tech-forward)
- Geometric x-height (premium feel vs. Poppins alone)
- Italic variant for emphasis
- Fallback: Poppins (Google Fonts, no network latency vs. external CDN)

## 10. Gotchas & landmines

**Hero frame loading:**
- 122 JPG images (public/hero-frames/0001.jpg — 0122.jpg) must exist and load
- GSAP ScrollTrigger scrubs frame-by-frame on scroll
- If frames don't load, hero is black
- Dev-env lag can cause frame skips; production smooth

**Lenis + GSAP ScrollTrigger integration:**
- `lenis.scrollTo()` conflicts with GSAP `scrollToPlugin` if both active
- Solution: Lenis integrated in `SmoothScrollProvider`, `ScrollToTop` uses `lenis.scrollTo(0)`
- Hero ScrollTrigger + Lenis: working (tested). Post-hero GSAP: broken. Use IntersectionObserver instead.

**3D Canvas (R3F) SSR issues:**
- Canvas parent cannot be hidden (opacity 0, clip-path, display none off-screen) at SSR time
- Solution: `dynamic(() => import('...'), { ssr: false })`
- Hydration mismatch if Canvas tries to render on server

**Google Calendar OAuth:**
- Requires GOOGLE_CLIENT_ID + GOOGLE_CLIENT_SECRET
- Refresh token saved in Supabase (or cookie) for availability checks
- First-time auth: manual Google login, scope: calendar.readonly + calendar.events.create
- Booking creation: uses refresh token to create event on Calendar

**Supabase auth edge cases:**
- Row-level security enabled: only service role (SUPABASE_SERVICE_ROLE_KEY) can bypass
- Feedback table: public insert allowed, anonymous user OK
- Availability table: only OAuth user can read/write (RLS)

**Resend email delays:**
- Transactional emails (booking confirmation) near-instant
- Broadcast/campaign emails throttled per plan
- Check Resend dashboard for bounces/spam flags

**Image optimization (Next.js Image):**
- Static imports: automatic srcSet + format negotiation
- Dynamic src: must specify width/height or use fill + objectFit
- Beware: fill + cover crops images; test responsive

**Tailwind v4 @theme:**
- Must restart dev server after editing globals.css @theme block (PostCSS cache)
- CSS variables (:root) override @theme in specificity. Use @theme for tokens, :root for fallback.

**TypeScript strict mode:**
- Enabled. `any` type errors in build.
- Components with optional props: interface, not params spread.
- API routes: Request/Response types from next/server.

**Bundle size gotchas:**
- GSAP full library ~80kb (minified). Only import modules you use.
- Three.js full library ~550kb. R3F Tree-shakes, but static meshes better than dynamic generation.
- Framer Motion ~45kb.
- Monitor with `npm run build` output (can add `--analyze` if webpack-analyze installed).

**Locale/timezone in booking:**
- Google Calendar default timezone: user's browser timezone
- Booking times stored as ISO 8601 in Supabase
- Consider timezone handling for international users (future).
