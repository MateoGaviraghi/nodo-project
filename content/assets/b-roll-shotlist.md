# Banco de B-roll — Tomas a tener listas para reels

> Una vez al mes (o cuando armás un set de grabación), juntar 30-50 segundos de cada categoría. Después se cortan al gusto en cada reel. Te ahorra tener que improvisar tomas en cada grabación.

---

## Categoría 1 — Manos en código

**Cantidad ideal:** 8-12 tomas de 3-5s cada una.

| # | Toma | Setup | Notas |
|---|---|---|---|
| 1 | Manos sobre teclado mecánico, vista cenital | Cámara arriba, 90° | Que se vean teclas iluminadas |
| 2 | Manos escribiendo, vista lateral 45° | Trípode bajo a la altura del escritorio | Foco en dedos |
| 3 | Manos en trackpad / mouse | Vista lateral | Movimiento sutil |
| 4 | Mano alcanzando café mientras la otra escribe | Cenital | Combina lifestyle + work |
| 5 | Dedos haciendo enter / escape / cmd-s | Macro lateral | Gesto definitivo |
| 6 | Cerrar laptop al final del día | Vista frontal | Storytelling cierre |
| 7 | Abrir laptop al inicio | Frontal | Apertura |
| 8 | Manos cruzadas detrás del teclado, pensando | Frontal | Pausa reflexiva |

## Categoría 2 — Pantalla con código / proyecto

**Cantidad ideal:** 6-10 capturas de pantalla y screen-records.

| # | Toma | Notas |
|---|---|---|
| 1 | VS Code / Cursor con código del ERP, scroll lento | Tema oscuro, fuente Fira Code o JetBrains |
| 2 | Terminal corriendo `npm run dev`, logs verdes | Texto legible |
| 3 | Vercel deploy completándose (✓ verdes) | Captura del dashboard |
| 4 | Supabase dashboard con tablas reales | Anonimizar datos sensibles |
| 5 | Chrome DevTools mostrando network limpia | Demo de performance |
| 6 | Browser navegando un proyecto del portfolio | Marcial, MB, Presisso, ERP |
| 7 | Lighthouse score 95+ apareciendo | Animación numérica |
| 8 | Git log gráfico (gitlens / lazygit) | Branches limpias |

## Cómo organizar el banco de b-roll

```
content/assets/b-roll/
├── 2026-04-mes/
│   ├── manos-001.mp4
│   ├── pantalla-erp-001.mov
│   └── ...
├── 2026-05-mes/
│   └── ...
```

**Naming convention:**
`YYYY-MM-categoría-NNN.{ext}`

**Backup:** copiar a Drive/iCloud cada vez que se sume material nuevo.

---

## Sesión de captura masiva (recomendado)

**1 vez al mes, 90 minutos:**
- 30 min — manos en teclado + pantalla código
- 30 min — setup oficina + caminatas
- 15 min — founder en cámara (no talking-head)
- 15 min — dispositivos con mockups en mano

Resultado: 15-20 minutos de b-roll usable que cubre 8-12 reels del mes.
